# 검증 기록

2026-10-13, 로컬 Node.js 환경에서 확인했습니다.

## 통과

- `npm run check`: 정적 페이지 8개, JSON 파일 8개, 로컬 링크, 필수 메타정보, 중복 HTML ID, 모든 JS 문법, Netlify 폼 선언, 모션 감소 설정.
- `npm test`: 데이터 검증 6개 + 오프라인 DOM 통합 검사 18개, 총 24개 통과.
- `npm run build`: `dist/` 생성. 배포 디렉토리에 개발 테스트, npm 패키지, 문서 또는 원본 ZIP은 포함하지 않습니다.
- `git diff --check`: 공백 오류 없음.

## 기능 검사 범위

실제 사용자 자료 대신 테스트 내부에서만 임시 데이터를 주입했습니다. 테스트 자료는 공개 JSON에 기록하지 않았습니다.

- 8개 페이지의 초기화 및 준비 상태
- 네 가지 연구 트랙과 최신 공지 3건/논문 2건 제한
- 팝업의 24시간 만료 및 저장소 차단 환경
- 공지 고정 순서, 카테고리+실시간 검색, 직접 링크와 모달 닫기
- 연도+트랙+키워드 복합 검색, 안전하지 않은 PDF 링크 차단
- 공지/실적/연구진 통합 검색, 비공개 자료 제외, 일부 자료 로드 실패
- HTML 문자열을 실행하지 않는 상세 본문·검색 출력
- 갤러리 이전/다음, 방향키 이벤트, 대체 텍스트와 캡션
- 파트너 레일의 접근 가능한 원본과 `inert` 복제본, 일시정지
- 메뉴 상태·모달 중복 방지·열기 버튼으로 포커스 복원 로직
- 언어 전환 시 폼 입력 보존, FAQ와 select 옵션 번역
- 이름/이메일/문의 유형/본문/동의 필수 검증
- 로컬 미리보기에서 실제 문의 전송 방지

## 확인하지 못한 범위

내장 브라우저가 로컬 미리보기 주소 접근을 정책상 차단했습니다. 다른 브라우저나 간접 경로로 우회하지 않았습니다. DOM 검사는 CSS 레이아웃이나 실제 브라우저의 네이티브 포커스 트랩을 검증하지 않습니다.

다음은 배포 후 실제 브라우저에서 확인해야 합니다.

1. 모바일 360/390px, 태블릿 768px, 데스크톱 1440px 화면의 레이아웃·로고·줄바꿈
2. Tab / Shift+Tab / ESC의 네이티브 dialog 포커스 이동과 배경 스크롤
3. Pretendard CDN, 외부 PDF/DOI/지도 링크의 실제 접근
4. Netlify Form detection 활성화, 실제 제출 저장, 수신 이메일 알림

GitHub Actions는 커밋 및 PR마다 동일한 데이터·DOM 검사와 빌드를 실행하도록 설정했습니다.
